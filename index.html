    02 C · Linux · sbrk

    memalloc — a drop-in malloc

    My own malloc, calloc, realloc and free. It manages the heap through sbrk and keeps a header in front of every block. Freed blocks are reused before the heap grows. It compiles to a shared library, so you can load it into existing programs with LD_PRELOAD.

    • Memory management
    • Shared libraries
    • Pointer arithmetic

    04 C · POSIX

    lsh — a Unix shell

    A small command-line shell built around a read → parse → execute loop. It reads input into a growable buffer and splits it into tokens. It runs programs with fork, execvp and waitpid. The built-ins (cd, help, exit) are looked up in a table of function pointers, so adding a new one only takes a single line.

    • Process control
    • Parsing
    • Function pointers
