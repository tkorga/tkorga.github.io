BILLO, a nonogram game.

A full-stack logic-puzzle game for the web. A Flask API handles the game, a React front end draws it, and the Stripe API processes in-game purchases in real time.

Type
Collaborative project
Timeline
Feb — May 2025
Stack
Python Flask · React · Stripe API
Scope
Full-stack, payments

frame 0 .problem

A puzzle people already love, online.

A nonogram is a grid puzzle. Numbers beside each row and column tell you how many unbroken runs of filled cells it contains, and the lengths of those runs. From the clues alone, you work out which cells to fill and which to leave empty. When you're done, the filled cells make a picture.

The goal was a web version that feels good to play and can also take payments for in-game purchases. That brings two kinds of problems together. The game needs fast, satisfying interaction, and the payment side has to be secure and reliable.
